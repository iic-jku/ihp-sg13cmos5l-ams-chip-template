# Top-Level LVS Reports

Per-cell LVS run folders of `chip_top`, written by `make klayout-lvs` (`chip_top.klayout.lvs/`) and by `make magic-lvs` (`chip_top.magic.lvs/`). Both folders are wiped at the start of each run, so they always reflect the latest run only.

The top-level LVS is not implemented yet, so this folder is still empty. The work in progress lives on the [`top-level-lvs`](https://github.com/iic-jku/ihp-sg13g2-ams-chip-template/tree/top-level-lvs) branch of the SG13G2 template and gets ported here once it runs through there. See [Layout Versus Schematic (LVS)](https://github.com/iic-jku/ihp-sg13cmos5l-ams-chip-template/blob/main/README.md#layout-versus-schematic-lvs) in the top-level README.
